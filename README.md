# Avin's Homebrew tap

```
brew install avin-lang/tap/avin
```

Installs `avin`, the compiler, with its standard library, runtime and editor grammars. macOS arm64.
Programs are linked with clang from Xcode's command-line tools; Sysl is installed as a dependency
for the standard library's bindings.

See [avin-lang/avin](https://github.com/avin-lang/avin) and its
[documentation](https://avin-lang.github.io/avin/).
